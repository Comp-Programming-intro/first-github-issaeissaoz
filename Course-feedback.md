# Course Reflection

## What I Learned

In this course I learned how to use GitHub repositories, commits, branches and pull requests.  
I also learned how markdown files work and how developers collaborate on projects using GitHub.

I practiced creating repositories, editing files, and pushing changes.  
I also learned how profile READMEs work and how to customize GitHub profiles.

## What I Am Still Confused About

I still need more practice with merge conflicts and working with branches.  
Sometimes Git commands and pull requests can be confusing at first.

## What I Liked

I liked the practical exercises because they helped me understand GitHub better by actually doing the work instead of only reading theory.

## What I Didn't Like

Some parts moved a bit fast, especially when dealing with branches and pull requests.

## What I Would Like More Of

I would like more real-world examples and beginner-friendly Git/GitHub workflow exercises.
